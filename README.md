 Somaj --- Social Development Events Platform Together, we build a better society.

Somaj is a community-driven social development platform that brings people together
to create, discover, join, and manage meaningful community service events. It helps
individuals take part in local initiatives such as winter clothing distribution, blanket
donation campaigns, community cleanups, tree plantation programs, and other social welfare activities.

The platform is designed to make community participation easier through a clean, responsive
interface and a straightforward event management experience.

Design & User Experience Somaj follows a modern, community-focused visual direction.

Dark green interface with lime-green accent colors.
Clear visual hierarchy and readable typography.
Consistent cards, buttons, and section spacing.
Community-focused imagery.
Responsive navigation and page layouts.
Light and dark theme support.
Authentication & Security Somaj uses authentication and authorization to protect user-specific functionality.

Public users can browse events and view event details.
Authenticated users can create and join events.
Private pages require an authenticated session.
JWT validation is used for protected API operations where required.
Event ownership is checked before allowing update or delete operations.
Password forms include the required validation rules.
